Reading the results

      
    
        
  • Each shot is one run of the circuit, so results vary a little between runs (about ±1–1.5 percentage points at 1000 shots).
    • 
        
  • The 3-qubit codes correct one error of their own type. The Shor code corrects any single-qubit X, Y or Z error, but not arbitrary multi-qubit errors. Independent noise on all data qubits can produce several errors at once.
    • 
        
  • A readout basis only reveals one kind of logical failure: basis Z shows logical bit flips, basis X shows logical phase flips.
    • 
        
  • Noise is applied only on the data qubits. Ancillas, syndrome extraction and recovery gates are noise-free, so this measures how well the code handles data errors, not full fault tolerance.
